# Matrial | متریال

اپلیکیشن آفلاین اندروید برای ثبت و مشاهدهٔ قیمت مواد اولیه، مثل آلومینیوم، ورق سیلیس‌دار و فولاد.

## امکانات

- افزودن و ویرایش متریال و واحد اندازه‌گیری
- ثبت قیمت در تاریخ‌های مختلف با انتخاب تاریخ شمسی
- نمایش آخرین قیمت هر متریال در کارت‌های ساده
- مشاهدهٔ نمودار با لمس کارت متریال
- ویرایش و حذف قیمت‌های ثبت‌شده
- پشتیبان‌گیری و بازیابی اطلاعات با فایل JSON

## نحوهٔ استفاده

۱. با دکمهٔ **+** و گزینهٔ **Item jadid** یک متریال اضافه کنید.
۲. از **Sabt gheymat** برای ثبت مبلغ و تاریخ استفاده کنید.
۳. روی کارت متریال بزنید تا نمودار آن باز شود.

برنامه با فهرست خالی شروع می‌شود. برای نمایش روند قیمت، حداقل دو قیمت با تاریخ متفاوت ثبت کنید.

## ذخیره‌سازی

اطلاعات در پایگاه دادهٔ SQLite روی همان گوشی ذخیره می‌شوند. برنامه به اینترنت، هاست یا حساب کاربری نیاز ندارد و میان دستگاه‌ها همگام‌سازی نمی‌شود.

پیش از حذف برنامه یا پاک‌کردن داده‌های آن، پشتیبان بگیرید. فایل‌های پشتیبان حاوی اطلاعات شما هستند؛ آن‌ها را در مخزن GitHub بارگذاری نکنید.

## وضعیت پروژه

نسخهٔ اولیه و در حال توسعه است. رابط کاربری تیره و فینگلیش است.

APK آزمایشی ساخته و امضای آن بررسی شده است. آزمایش کامل روی دستگاه‌های مختلف هنوز انجام نشده است. نام قبلی «Mayeh» ممکن است در بخش‌هایی از کد و نسخهٔ نصبی فعلی دیده شود.

## پیش‌نیاز نصب

اندروید ۸ یا جدیدتر.

## ساخت از سورس

- JDK 17
- Android SDK 35 و Build Tools 35.0.0
- Gradle 8.9

پروژه را در Android Studio باز کنید، مسیر SDK و کلید امضای محلی خود را تنظیم کنید و وظیفهٔ زیر را اجرا کنید:

`gradle :app:assembleDebug`

کلید امضا و فایل `local.properties` نباید در GitHub ثبت شوند.
